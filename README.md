# `compta-copro-gsheet` : analyse des dépenses d'un compte de copropriété

Création d'un fichier au format gSheet pour partage via Google Drive des données avec les autres membres du conseil syndical, voire du syndic.

Il s'agit d'importer les fichiers exportées depuis le site du syndic (au format csv), de faire une base de données unique des dépenses pluri-annuelles.
Le but est de faire une synthèse pour le comparer avec le RGDD (Relevé Général Des Dépenses).
D'abord avec la version numérique, puis avec la version scannée comportant les factures.
